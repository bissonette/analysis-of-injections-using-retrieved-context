# Сравнение версий фильтра по журналам Colab

Первый прогон на Qwen2.5-7B-Instruct даёт точку отсчёта для сравнения доработок фильтра.

| Показатель | Результат |
| --- | --- |
| Успешные инъекции без фильтра | 137 из 1194 (11,47%) |
| Успешные инъекции с фильтром | 92 из 1194 (7,71%) |
| Успешные инъекции класса «Подмена задачи» с фильтром | 55 из 490 |
| Из них фрагмент передан целиком | 54 из 55 |
| Чистые примеры, затронутые фильтром | 54 из 889 (6,07%) |
| Чистые ответы, сохранённые дословно | 850 из 889 (95,61%) |

В исходном журнале 305 повторных строк с уже учтёнными ключами чистых примеров. Доля затронутых и доля дословно сохранённых ответов приведены по уникальным ключам. Дословное совпадение измеряет изменение текста, поэтому полезность изменившихся ответов стоит оценивать отдельно по необходимым для ответа сведениям.

## Анализ сохранённых результатов

В [блокноте Colab для просмотра результатов](../notebooks/colab_compare_results.ipynb) можно открыть пару файлов доработанной версии. Для парного сравнения включите `COMPARE_WITH_BASELINE` и загрузите также исходные файлы. Блокнот показывает таблицу и позволяет скачать отчёт.

`compare_colab_results.py` читает готовые журналы `.jsonl` и одноимённые сводки `.json`. Для одного журнала он считает общие показатели и разбивки по классу влияния и источнику.

```sh
python scripts/compare_colab_results.py baseline.jsonl --out baseline-audit.json
```

С двумя журналами скрипт сверяет ключи примеров, источники, критерии и записанные параметры модели. В отчёте отдельно указано, сколько примеров между версиями перестали удовлетворять критерию успеха и сколько начали ему удовлетворять. Строка сравнения без фильтра помогает увидеть расхождения между прогонами даже при совпадении записанных настроек.

```sh
python scripts/compare_colab_results.py baseline.jsonl --candidate updated.jsonl --out comparison.json
```

При несовпадении выборок или условий, конфликте повторных записей либо незавершённых примерах скрипт завершает сравнение с сообщением о причине. Отчёт содержит хеши журналов, условия и агрегаты. Версию фильтра для каждого журнала нужно фиксировать рядом с файлами прогона, поскольку исходная сводка Colab её не записывала.
